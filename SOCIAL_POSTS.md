## Hacker News (Show HN)

**Title:** Show HN: create-ai-chatbot – Scaffold a full-stack AI chatbot in seconds

**Body:**
I built the same chatbot architecture three times (real estate concierge, hackathon project, client work). Every time: FastAPI backend, React frontend, OpenRouter for LLM, streaming SSE, floating chat widget. The only thing that changed was the system prompt and tools.

So I packaged it into a CLI tool: `create-ai-chatbot`

What you get:
- FastAPI backend with streaming /chat endpoint
- Vite + React frontend with floating chat widget
- OpenRouter integration (100+ models, free tier)
- Ready to deploy: Render (backend) + Vercel (frontend)
- One command: `npx create-ai-chatbot my-chatbot`

It's MIT licensed. I'd love feedback on what template options to add next (Next.js App Router, Anthropic direct, pre-built tool templates).

npm: https://www.npmjs.com/package/create-ai-chatbot
PyPI: https://pypi.org/project/create-ai-chatbot

## Reddit (r/SideProject)

**Title:** I packaged my AI chatbot architecture into an open-source scaffolding tool

**Body:**
After building the same chatbot stack 3 times for different projects, I finally packaged it.

`create-ai-chatbot` scaffolds a full-stack AI chatbot:
- Backend: FastAPI with streaming SSE
- Frontend: Vite + React with floating chat widget
- LLM: OpenRouter (supports 100+ models)
- Deploy: Render + Vercel configs included

Usage:
```bash
npx create-ai-chatbot my-chatbot
cd my-chatbot
# backend: pip install -r requirements.txt && uvicorn main:app --reload
# frontend: npm install && npm run dev
```

I've used this architecture for a real estate concierge (Wadan Developments), a hackathon (Z2A apartment agent), and a client project. It always works well.

Would love to hear what features you'd want. Planning to add Next.js template, more themes, and pre-built tool templates (RAG, web search).

https://github.com/binadacode/create-ai-chatbot
